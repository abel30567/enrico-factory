# Sample production: Primal (Argelia)

The system's first sample: a story set in the Primal TCG world (https://primaltcg.com) with the
pirate Argelia as lead.

The sample's material (lore sources, a card index, art reads, a world draft, a first storyboard, the
owner's canon rulings and the art itself) is not in this repository and does not belong here. Wave 3
created the production's own repository with `factory init` (#101); the material is imported there by #102.

## First tickets for the system (wave 3)

- Research: the Three Aces across cards, art and lore text.
- Canon: apply the owner's rulings to the world draft and the episode 1 storyboard.
- Story: a premise room for a Three Aces episode.

---
format: serial-microdrama
runtime: 60-90             # seconds, minimum-maximum
beats: pickup, event, value change, open question
shots: 5-8
skips: outline
---
Structure: one event per episode, ending open, in a serial.

The pickup must resolve or restate the previous episode's cliffhanger within about five seconds, so a
new viewer can follow. The event must be a single thing that happens on screen, not a summary of
several. The value change must turn one value for the main character, from safe to threatened, trusted
to betrayed, or the reverse. The open question must end the episode on something unresolved that the
next pickup can answer. The story editor checks that there is exactly one event and one value change.
